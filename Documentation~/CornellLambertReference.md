# Cornell Box 独立 Lambert 数值参考

`Tools~/Diagnostics/CornellLambertReference.py` 为共享 `unity_fixture.json` 建立精确旋转盒体与顶部矩形光源模型，输出接收点的场景线性 RGB `E/π`。它不依赖 SDF、Surface Cache、SH、屏幕历史、曝光或拟合增益，供后续区分照明传递误差与重建噪声。

这是明确定义的 **Lambert 模型**，不是 OpenPBR、Unreal 或当前 SDF 近似的等价性证明。它使用导出的常量线性反射率；所有面使用双侧不透明漫反射，顶部光片也双侧反射 / 遮挡，但只向下发光。天空和环境为黑，不含镜面、透射、纹理、体积或材质粗糙度响应。实际引擎比较前仍需核对这些语义、接收点和 GPU 材质量化。

## 积分与 π

每个散射顶点均匀采样光片面积，贡献为 `throughput × Le × area × cosReceiver × cosEmitter / (π × distance²)`，用精确几何遮挡判断可见性。随后按余弦半球采样漫反射路径；BRDF 的 `ρ/π` 与余弦采样 PDF 相消，每次反射只再乘一次 `ρ`。接收点本身不乘反射率，保持输出为 `E/π`。

光片的直接发光已由面积采样计算，BSDF 路径命中光片时不重复加 `Le`，仍可继续追踪它的漫反射。`bounces=0` 只有接收点直接照明；`bounces=8` 另计最多八次漫反射。各阶均值分别保存，不把增加阶数与增加采样数混为一项。

## 首次数值验证

四项独立 Python 检查通过：盒体内部 / 旋转盒交点，无遮挡平行矩形的解析形状系数与黑背面，余弦分布 / 单位长度及光照四倍线性响应，以及黑反射率场景不重复计算 BSDF 光源命中。没有启动 Unity Test Framework。

矩形检查的解析值使用：令 `X=a/h`、`Y=b/h`，`F=2/π × [X/√(1+X²) × atan(Y/√(1+X²)) + Y/√(1+Y²) × atan(X/√(1+Y²))]`。独立面积采样均值落在五倍估计标准误内；这项检查验证直接照明的几何因子与 π，不代替多次反射的场景对照。

实际五点运行位于 `E:/VividRP_GI_Evidence/CornellLambertReference-20261114-173655-289207`。每点 **131,072 条路径**、最多八次反射，使用独立种子。下表为线性 RGB 均值与各通道的 **1σ Monte Carlo 标准误**，不是引擎误差：

| 接收点 | 平均 RGB E/π | RGB 标准误 |
|---|---|---|
| 红墙 | 12.4861, 12.1559, 11.2740 | 0.01493, 0.01399, 0.01256 |
| 绿墙 | 11.8607, 11.4449, 10.7136 | 0.01357, 0.01270, 0.01152 |
| 后墙 | 6.7146, 7.0589, 5.8597 | 0.01313, 0.01224, 0.01023 |
| 地面 | 15.2886, 15.0552, 14.0590 | 0.01119, 0.01043, 0.00912 |
| 天花板 | 3.5537, 3.1091, 2.1618 | 0.01522, 0.01401, 0.01138 |

每点的 GPU 像素坐标、实际命中物体、精确位置和法线、独立种子、各阶贡献均在 `reference.json`。GPU 读回 Y 相对规范 EXR / 相机图像行翻转，工具明确进行这一转换。源码、实际执行脚本和夹具已保存并核对 hash；没有保存逐路径原始数组或大量图片。

## 3.5 cm 缝隙与 4 cm 偏移的机理检查

另用同一模型检查光片中心正上方的天花板点 `(0,3,1.85)`、法线向下；光片高度为 `2.965`。将查询位置沿法线移动 4 cm 后，Y 为 `2.96`，已经到光片另一侧。两点各 131,072 条路径、最多八次反射，分别使用独立种子，结果如下：

| 模型中的接收位置 | 平均 RGB E/π | RGB 标准误 |
|---|---|---|
| 原天花板点 | 0.007784, 0.006138, 0.003070 | 0.000487, 0.000418, 0.000262 |
| 向内移动 4 cm | 5.76544, 5.02118, 3.67882 | 0.02266, 0.02136, 0.01766 |

两点的直接发光项都为零；差异来自越过不透明光片后看到的反射照明。该对照说明更长历史不能修复这种几何起点差异，值得优先验证近邻几何的起点约束。它**不是 VividRP 的实际偏移消融**：SDF 壳厚、自命中修正、卡片位置和实际 GPU 发射点仍需核对，不能把此数值直接解释成当前画面误差。

独立数据为同目录 `origin-offset-reference.json`，实际脚本、输入点、夹具及 `source-offset-verification.json` 保留。后续先检查 GPU 是否发生同样跨面，再分离 Gather 发射点与 Surface Cache 积分的影响，验证首命中、黑覆盖、能量和动态响应；暂不降低全局 bias 或修改正常参数。

## 复现与后续判定

```powershell
python -B Tools~/Diagnostics/test_cornell_lambert_reference.py
python -B Tools~/Diagnostics/CornellLambertReference.py NEW_OUTPUT.json --samples 131072 --bounces 8
```

输出文件必须不存在。`--points` 可提供含 `position`、单位方向 `normal` 的点列表；默认选择五个现有 ROI 中心的实际表面。输入、结果均须有限，反射率限定在 0～1；参考输出带夹具 SHA-256。

本次只建立数值参考，尚未据此核验当前引擎五点误差，也没有推广 GI 参数。五个点不足以证明整幅画面的噪声、运动稳定性或颜色正确。后续扩展到同机位的平面采样点 / 区域，并分别统计固定误差、最终时间方差、能量和新露出区域；Surface Cache 的有限分辨率、SDF 几何偏移及材质模型差异仍应单独定位，不能用全局增益抹平。
