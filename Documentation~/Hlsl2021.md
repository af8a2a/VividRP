# HLSL 2021 pilot: UberPost

Validated on 2026-11-06 with Unity `7000.0.0a16` (`0745a91df592`),
CoreRP `17.7.0`, and an NVIDIA GeForce RTX 5070 Ti.

Unity's [a16 release notes](https://unity.com/releases/editor/alpha) introduce
`#pragma hlsl_version 2021` for DXC-backed D3D12 and Vulkan compilation.
The language changes include templates, operator overloads, scalar short-circuit
evaluation, stricter struct conversions, and loop-variable scope changes; see
Microsoft's [migration guide](https://devblogs.microsoft.com/directx/hlsl-2021-migration-guide/).

## Production change

`Shaders/Core/Private/UberPost.shader` now explicitly declares:

```hlsl
#pragma use_dxc
#pragma hlsl_version 2021
```

UberPost is the standard render graph's combined color-grading, bloom, vignette,
and film-grain pass. Its existing source and shared includes already compile
under HLSL 2021; no formula, resource binding, keyword, or CPU interface needed
to change. This is a single-shader opt-in, not a package-wide language upgrade.

## Results and limitation

| Check | Result |
| --- | --- |
| Standalone DXC DXIL, HLSL 2018 and 2021 | Both passed all 64 keyword combinations, vertex and fragment entrypoints |
| Standalone DXC SPIR-V, HLSL 2018 and 2021 | Both passed the same matrix |
| Unity D3D12 UberPost compilation and GPU comparison | 64 variants × 2 uniform cases, 128 image pairs; maximum absolute difference 0 |
| Unity Vulkan UberPost compilation and GPU comparison | 64 variants × 2 uniform cases, 128 image pairs; maximum absolute difference 0 |
| Unity D3D12 and Vulkan template/operator probe | Failed: `template` and `operator` are reserved keywords |
| Unity D3D12 scalar short-circuit probe | Failed: the right-hand side still executed when the left-hand side was false |

The standalone compiler was DXC `1.9.0.5512` from the installed Vulkan SDK.
The matrix includes all six declared keyword toggles, including redundant
combinations. The GPU comparisons use deterministic 16×16 HDR input, exposure
on/off, LUT on/off, and procedural/masked vignette. Both shader versions use
DXC; the baseline omits `hlsl_version` and uses Unity's default language mode.
An analytic no-effect sample also checks that the draw produced real output.

The positive standalone language probe compiles with `-HV 2021`, and fails with
`-HV 2018`. In Unity, both `.compute` and ordinary `.shader` probes with the
documented pragmas rejected the new syntax. The independent D3D12 semantics
probe returned green `0.99` instead of `0`: its false `&&` expression still
called a function that changed a local variable from `0` to `99`.
Removing `use_dxc` did not enable the language features either.

Therefore this installation has **not verified effective HLSL 2021 language
selection inside Unity**, despite accepting and rendering UberPost with the
new declaration. The results suggest an Editor/compiler integration issue;
the exact engine cause has not been established. Keep new syntax adoption
limited until the language probes pass. Existing UberPost output is validated
only for the stated inputs; full-scene rendering, other graphics APIs, and
performance are not covered.

## Reproduce

Standalone compilation (512 successful compile invocations in the full matrix):

```powershell
python Tools~/Validate-Hlsl2021.py
```

Use `--backend dxil` or `--backend spirv` for one output path, `--dxc` for a
compiler executable, and `--core-package-root` for a different CoreRP checkout.
`--output-directory` selects a parent for the unique scratch directory. It must
be outside the containing Unity project. The tool copies the include closure;
it creates no junctions or symlinks and retains binaries, logs, and `report.json`.

Prepare an independent, include-only Unity project:

```powershell
python Tools~/Validate-Hlsl2021.py --prepare-unity-project
```

Run the printed project with the installed a16 Editor:

```powershell
unity run <printed-project-path> --editor-path <Unity.exe> --timeout 180 --format json -- -force-d3d12 -executeMethod Hlsl2021UnityProbe.Run
```

Replace `-force-d3d12` with `-force-vulkan` for Vulkan. Do not use `-nographics`.
Add `-vividHlslLanguageOnly` to skip the UberPost comparison and run only the
language probes. `Hlsl2021UnityResult.txt` records the image-comparison outcome;
`Hlsl2021LanguageResult.txt` records a language-only run. Exit code `2` indicates
a language-probe failure even if the independent UberPost checks passed.
Fatal setup or image-comparison errors produce `Hlsl2021UnityFailure.txt` and
exit code `1`.

These are direct Editor compilation/GPU probes, not Unity Test Framework tests.
The containing project and its open Editor are not used by the probe. No
temporary include links were created during this validation.
