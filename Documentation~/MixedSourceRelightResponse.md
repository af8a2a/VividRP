# 天空、自发光与混合光源的 GI 变化响应

2026-11-12，Unity 7000.0.0a16 / D3D12 / RTX 5070 Ti。Cornell Bright 同机位，原生 Screen Probe Gather 始终为 **16 px、每探针 8 条射线**。未保存对场景、材质、Profile 或管线资产的实验修改。

## 实现

### 有条件的统一光源换算

将原来的纯太阳光换算扩展为太阳、天空和常量自发光：只有所有实际贡献源在各 RGB 通道满足同一比例，才换算已发布的高阶 incident lighting，以及原生 Gather 的方向、anchor、采样引导和像素历史。例如纯天空、纯自发光、三光源共同翻倍均可复用；固定太阳、单独增强发光不满足条件。

`VividMeshSdfGpuScene` 分开记录 `TransportVersion` 与 `EmissionVersion`。几何和所表示的 Albedo / coverage / 卡片输入变化会改变输运版本；单独发光变化可保留几何历史。每个发光表面都与固定的首个比例基准比较，防止大量表面逐个积累容差。跳过多个发光 revision、从零恢复正能量、非有限值、负能量和超过 8 倍的变化均不通过换算。

天空另要求内容 hash、方向、追踪范围和启用状态兼容。新增两个 kernel 对源 cubemap 全部六面 mip 0 求最大 RGB；每个 thread group 先局部归约，再写入一个 uint 结果。相机提交后异步回读，按内容 hash 缓存峰值，强度变化无需重测。缓冲与回调复用；尚未获得可靠峰值、内容非有限或 cubemap 大于 1024 时走重建，不以下采样结果冒充上界。

用 `max(sun + emission + skyGain * skyPeak) * (orders+1) <= 60000` 保守排除可能饱和的高阶历史。发光和太阳的通道比也必须与天空一致。天空内容 / 旋转变化不能通过亮度乘法处理。

### 独立变化时加快首轮重建

混合光源独立变化时不缩放整张缓存。新增 `surfaceCacheRelightSweeps`，默认 **8**，范围 1–8：对布局和输运仍兼容的小场景，允许一个渲染帧依次完成多个反弹 sweep，仅加快首个采样批次。每一阶仍读取**刚计算的上一工作阶**；不把保留的旧高阶结果反馈到低阶。

同时受以下约束：

- 卡片数必须不超过已有 `surfaceCacheFullUpdateCardLimit`，并从完整 sweep 起点开始。
- `cards * samples * sweeps <= 65536` 的 ray-work 上限；单个既有 sweep 已超过时仍只执行一个。
- 后续采样批次恢复原调度，累计样本数和最终反弹阶不变。固定 A/B 工作 atlas 与逐阶累积路径均支持。

37 卡片、64 samples、8 阶时，突变帧从 1 个 sweep 增至 8 个；Gather 仍只有 8 条射线。大场景继续原卡片增量预算，高样本参考不会无条件执行八轮。默认持续采样累积仍为 false。

### 屏幕命中光照失效

找到并修正了旧光照回灌：此前屏幕颜色有效性主要检查太阳，发光关闭后仍可能采集含旧发光 / 旧 GI 的上一帧颜色。现在同时检查场景 revision、天空能量 / 内容和首轮 Radiosity 重建状态。

失效期间仍可使用屏幕几何命中，但通过当前 SDF / Surface Cache 计算命中光照。新目标阶就绪后恢复屏幕颜色使用。原生历史只在统一比例条件满足时保留；ReSTIR 的 reservoir / 方差历史不参与这套换算。

## 实验设置与度量

1920×1080，原相机位置 `(1.62,1.66,-1.7)`、旋转 `(0.03591185,-0.16398631,0.005973937,0.98579067)`；固定 EV100=8，关闭 AA 和 Local Exposure，固定随机帧序列。保留 Adaptive 5×5、空间 anchor、2-pass À-trous、像素历史上限 16，关闭方向采样引导和 Far Cache。

测试源：

- 天空为临时 HDR cubemap，线性 RGB `(80,100,120)`，GPU 实测峰值 **120**；开启 SDF 天空遮挡。
- 自发光为 Back 的临时代理，保留烘焙材质 identity；基准线性 RGB `(240,80,24)`，经 gamma 转换后填写代理颜色，再由运行时读取线性值。
- 混合组太阳基准 900 lux，关闭太阳与天空模型的耦合；其余两个源固定，只改变被测源。纯天空 / 发光组的其他源为零。
- 升光为 `0.5 → 1`，降光为 `1 → 0.5`，关灯为 `1 → 0`。混合关灯仍保留其余光源，不应变黑。

每组预热 192 帧，测量 256 帧，在测量第 64 帧改变参数。主 Radiosity 为 8 阶、64 rays/texel/batch、16 批；另以非持续累积的固定 128-ray 模式复测混合发光。18 组 A/B 共 **16128 个实际渲染帧**。

直接读回天花板区域 `x=912,y=970,w=96,h=48`（GPU 底部坐标）的 Resolve、Temporal、最终 GI，以及 37 张有效卡片；未把 atlas 的 11 张空白填充算作能量。亮度为线性 `RGB * coverage` 的 Y。首帧误差相对同组旧路径末段 64 帧均值；纯关灯残留则相对变化前均值。

## 结果

| 光源组 | 升光首帧误差：旧 → 新 | 降光首帧误差：旧 → 新 | 关灯首帧：旧 → 新 |
|---|---:|---:|---:|
| 纯天空 | −11.31% → **−1.08%** | +18.30% → **−1.21%** | 原亮度的 20.18% → **0%** |
| 纯自发光 | −32.01% → **+1.30%** | +59.42% → **+1.07%** | 原亮度的 61.32% → **0%** |
| 混合，仅改变太阳 | −10.00% → **−0.80%** | −7.41% → **+0.19%** | −4.86% → **+1.67%** |
| 混合，仅改变天空 | −6.41% → **−0.79%** | −0.55% → **−1.08%** | +3.69% → **−1.48%** |
| 混合，仅改变自发光 | −14.75% → **−0.78%** | +9.69% → **−1.51%** | +30.54% → **−2.64%** |
| 固定样本，仅改变自发光 | −14.67% → **−0.74%** | +9.70% → **−1.44%** | +30.50% → **−2.53%** |

混合关灯列是相对保留光源的最终亮度误差，不能与纯关灯残留百分比直接互换。

- 纯天空 / 自发光关灯从变化当帧起，所有测量帧的区域 Resolve、Temporal、最终 GI RGB 均为零。
- 非零目标的新路径全部从变化当帧起连续 8 帧位于 ±5%。纯发光升光旧路径需到变化后第 54 帧才达到这一条件；混合发光升光为第 27 帧。
- 新路径前 32 帧区域均值最大正过冲为 **+1.67%**；这不是逐像素误差上界。
- 混合天空关灯的前 32 帧平均绝对误差有回退：**1.60% → 3.62%**，最大负偏差 **−4.63%**。完整首轮消除了旧能量等待，但独立光源变化仍需重建 8-ray Gather 历史，冷启动方差没有全部解决。未宣称所有指标改善。

### 最终能量

18 组最终有效卡片数据全部**逐位一致**。主混合组末段像素均值变化最大 **0.063%**；固定样本混合组最大 **0.077%**。纯发光升光仍有 +0.422% 的后段历史差，因此追加长序列而未直接将它解释为最终漂移。

延长纯发光升光至测量 1024 帧，即变化后 **960 帧**：

| 测量帧窗口 | 新旧区域均值差 |
|---|---:|
| 192–255 | +0.422% |
| 256–511 | +0.082% |
| 512–767 | +0.032% |
| 768–1023 | +0.023% |
| 960–1023 | **+0.017%** |

最后 64 帧逐帧均值最大差 **0.022%**，最终卡片仍逐位一致。观察到历史差持续缩小，没有持续增亮。参考是同一 SDF / Surface Cache 求解器的旧路径，不能据此宣称独立路径追踪或 Unreal 的绝对能量一致。

## 保护、限制与验证

有效 GPU 控制验证了：无太阳光时纯发光仍可换算；太阳 / 天空 / 发光共同翻倍可换算；几何移动拒绝换算和首轮加速；天空旋转拒绝换算、改走完整重建；将 sweep 上限设为 2 后，实际在四帧依次推进到 2 / 4 / 6 / 8 阶。

材质 GPU 控制中，修改临时代理 `BaseColor` 没有改变当前 SDF 从 **source Material** 读取的 Albedo，因此该组被标记无效并排除。没有用它声称 GPU 材质保护通过。实际表示的 Albedo / coverage / 卡片字段合同已做 CPU 检查，输运版本拒绝有实际几何 GPU 控制；当前功能针对 SDF 所表示的常量发光语义。

其他验证：

- 38 个相关 compute kernel 的 DXIL / SPIR-V 编译通过；六个相关 Unity compute 的消息无错误。
- 当前线程预热后重复 4096 次新增策略调用为 **0 B**；不代表整个渲染帧或异步回读内部全部无分配。
- CPU 检查覆盖未知 / 过高天空峰值、超尺寸天空、内容 / 方向变化、独立源比例不一致、很多发光表面的容差漂移、屏幕旧光照拒绝、ReSTIR 历史拒绝与预算边界。
- `DiffuseSurface` 保持 64-byte stride，字段偏移为 0 / 16 / 32 / 48，已与 HLSL 核对。
- 临时 hook / flag 清除，材质代理、太阳、机位和 Profile 恢复，保留实验开始时的活动场景。
- 补充了 `SdfRadiosityBudgetTests`。Editor 运行中未启动 Unity Test Framework；需关闭 Editor 后运行该组测试。

**没有采集 GPU 时间戳。** 独立混合光源突变时的首轮最多多执行八个卡片 sweep，存在突发 GPU 开销；可将 `surfaceCacheRelightSweeps` 降到 1–2。峰值测量只随天空内容变化进行，不随单独强度变化重复。本轮没有验证每帧持续变化的天空、贴图 / 程序发光或移动几何的画质。
