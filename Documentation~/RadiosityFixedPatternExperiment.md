# Cornell Box：radiosity 阶数与固定斑块来源实验

2026-11-11；Unity 7000.0.0a16，D3D12，RTX 5070 Ti。

## 结论

**固定 16 射线的 Surface Cache radiosity 确实会留下固定采样误差，后墙尤其明显；但它不足以解释当前天花板的大部分强噪声。**

- 卡片解在采集期间完全冻结，误差图在前后半段可重复；只换 radiosity seed 就会改变误差图，确认存在源缓存的固定误差。
- 8 阶、16 射线相对 4096 射线的天花板平均能量偏高约 **1.21%**。去掉整体增益后，固定形状误差 RMS 只有 **0.109**，约为参考均值的 **0.20%**；最终像素区域的对应固定误差为 **0.046**。
- 后墙的去增益固定误差 RMS 为 **0.427**，换另一 radiosity seed 后可达 **0.856**。这部分有明确的 Surface Cache 采样来源。
- 天花板最终像素的时间 RMS 从 **2.037 → 2.017**，归一到平均亮度后为 **3.84% → 3.85%**，没有降噪收益。0 阶时仍有 **1.812** 的时间 RMS，说明强时间噪声在关闭卡片间 radiosity 后依然存在。

因此，可以确认源缓存贡献了部分固定偏差，但不应把天花板当前的大块噪声全部归因于 radiosity 的低角度采样。继续定位 Gather 的时间历史和重建更有依据。本实验保持卡片 **8×8 空间分辨率**不变，尚不能排除其空间离散、捕获覆盖或其他 Surface Cache 误差。

## 控制变量与实现

沿用 Cornell Comparison Camera、3600 lx、EV8、1920×1080、16 px 探针网格、每探针 8 条射线、Adaptive 5×5、空间 anchor、像素历史 16 与两轮 À-trous。使用原生 Screen Probe Gather / Hybrid / realtimeOnly，不混入 APV 或环境漫反射回退。

为固定各组的射线方向，所有组关闭重要性引导，并使用相同 Gather 帧号序列。对照只改变卡片 radiosity 阶数、每 texel 角度样本数和指定的 radiosity seed。没有改变 π、Albedo、太阳光、曝光、卡片布局、材质或几何。

新增 `surfaceCacheRadiositySamples`，默认仍为 **16**，范围 16–4096。`EditorRadiositySeed` 仅作为 Editor 诊断控制，默认 0；seed B 实际值为 **912731**。采样数和 seed 纳入 radiosity 解及 GI 历史的有效性条件，改变后重建卡片解。

默认 16 射线、seed 0 的完整 atlas 与修改前已保存的 8 阶 atlas **逐位一致**，验证默认解未改变。

## 实验矩阵与有效性

| radiosity 阶数 | 每 texel 射线数 | seed | Gather 测量帧 |
|---|---|---|---:|
| 0 / 1 / 2 | 16 | A | 各 512 |
| 8 | 16 | A | 1024 |
| 1 / 2 | 1024 | A | 各 512 |
| 8 | 1024 / 4096 | A | 各 1024 |
| 8 | 16 | B | 1024 |

0 阶表示关闭卡片间 radiosity，Screen Probe 仍然追踪直接受光表面，因而仍有漫反射间接光。第 N 阶解包含前 N 次卡片传播，不是仅保留第 N 阶反弹。

高样本卡片组每帧只更新一张卡片，每阶完整发布后才允许下一阶读取。预热为 `128 + 37*阶数` 帧；16 射线组预热 128 帧。每个测量帧都确认已达到目标阶数、更新数为 0。

共执行 **8511 帧**，其中 **6656 帧**参与测量。每组 8 阶 Gather 累积 **8192 条射线 / 探针**，其他阶累积 4096 条。这里的高样本 radiosity 指**每个卡片 texel、每次反弹传播的 1024 / 4096 条射线**，与 Gather 的累积射线数是不同变量。

8 个非零阶组的采集首尾，37 张卡片、每卡 8×8 的全部已分配 texel 均逐位一致。覆盖掩码相同，1952 个卡片 texel 有效；不能把其余 texel 直接解释成场景几何覆盖缺失。所有测量帧 VP 相同，太阳强度和光色不变；接收点几何与法线检查通过。

## 固定误差与 Gather 噪声的分离

同阶低样本 / 高样本组使用相同 Gather 随机方向。对每个接收点累积两组贡献之差，减少 Gather Monte Carlo 噪声的干扰。另将低样本组乘以参考能量比例的整体增益移除：

```text
gain = mean(Y_low) / mean(Y_reference)
fixedShape[p] = mean_t(Y_low[t,p] - gain*Y_reference[t,p])
```

同时报告配对差均值的标准误差，以及前后半段误差图的相关性。相关性针对同阶误差图，不把真实光照梯度自身的重复性当作错误证据。

| 比较 | 天花板形状 RMS | 配对 Gather 均值 SE RMS | 前后半段误差相关性 |
|---|---:|---:|---:|
| 1 阶：16 vs 1024 | 0.0967 | 0.0493 | 0.585 |
| 2 阶：16 vs 1024 | 0.1042 | 0.0493 | 0.638 |
| 8 阶：16 vs 4096 | 0.1090 | 0.0356 | 0.813 |
| 8 阶：1024 vs 4096 | 0.0130 | 0.0103 | 0.289 |
| 8 阶：seed B 16 vs 4096 | 0.1394 | 0.0372 | 0.865 |

扣除配对 Gather 均值噪声的估计方差后，8 阶 16 vs 4096 的天花板固定形状 RMS 约 **0.1030**。1024 vs 4096 的对应值约 **0.0080**，已接近有限 Gather 记录的分辨能力。

后墙 16 vs 4096 的形状 RMS 为 **0.4273**，均值 SE 为 **0.0389**，前后半段误差相关性 **0.985**；只换 seed 的固定形状差 RMS 为 **0.7373**。这些结果支持“后墙确有来自卡片采样的稳定偏差”。

## 源缓存的角度采样收敛

| 8 阶比较 | 有效卡片 texel 的源误差 RMSE | P95 绝对误差 |
|---|---:|---:|
| 16 vs 4096 | 6.4916 | 15.8202 |
| 1024 vs 4096 | 0.3170 | 0.7409 |
| seed A 16 vs seed B 16 | 9.0960 | 23.1127 |

提高角度样本确实显著减小了卡片源误差。其传到相同天花板接收点后的影响更小：1024 vs 4096 的均值仅差 **0.0423%**。这表明 1024 已足以作为本轮积分区域的较稳定参考，但不能把 4096 解视为无误差物理真值；8×8 空间布局及 SDF / 捕获近似仍相同。
