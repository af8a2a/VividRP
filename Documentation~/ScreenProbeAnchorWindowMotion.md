# 长窗口 anchor 的固定轨迹验证

后续进展：[生产路径验证](ScreenProbeAnchor512Production.md)已完成，Emissive Cornell 已保存为 FP32 / 512；下文的“未推广”描述对应本次运动实验结束时的状态。

继 [静止 FP32/512 候选](ScreenProbeAnchorPrecisionExperiment.md) 通过门槛后，本轮只验证运动稳定性、新露出区域与板边色差。**正常 Profile 仍为 128，没有推广 512 默认值。**

证据为 `E:/VividRP_GI_Evidence/ScreenProbeAnchorWindowMotion-20261114-195008-007`。原生 Screen Probe Gather 保持 1920×1080、16 px / 8 rays、guarded anchor 预滤波、四轮 À-trous，源为已收敛的 8 阶 / 64 样本 / 32 批 Radiosity，太阳、天空和附加近场遮挡为零。

## 输入与轨迹

`ScreenProbeAnchorWindowCapture.cs` 新增 `motion` 模式。每组先回原机位，确认两次真实渲染的 VP 正确后才清理历史；源稳定八帧后开启独立 epoch。每组静止预热 4,096 帧，再执行两轮相同的 128 帧轨迹，逐帧采集 256 帧。局部 X/Z 平移为 `0.28/0.06 × sin(t)` 米，yaw 为 `−7 × sin(t)` 度；采样帧号为 `1733 + epochFrame`。

两次 FP16/128 基线先通过 A/A，随后运行 FP32/512：

- **2,573 对** GPU 检查点逐位相同；两组 **8,704 帧** CPU 状态逐项相同。
- 三组共 **13,056 帧**的历史与场景版本检查通过，没有意外失效或源卡片更新。
- 256 个测量帧的 raw、探针几何、packed pixel geometry 和 VP 在基线与候选间一致，重复两轮轨迹的 VP / 几何一致。
- 两组实际 anchor / previous / prepared / reconstructed 格式分别为 RGBA16F / RGBA32F。四个实际 DX12 kernel 二进制与静止实验相同。
- 源始终为标准 SHA-256 `8d1b4e596e3ef067de430082d0d25763b9df83c25b57422acbdd0e33c73d6e62`。原机位 0 / 4,095 / 4,096 帧的几何与 raw 也与静止实验一致。
- 捕帧前后 **2,789 份**源码、**4,124 份**外部输入及实际执行脚本指纹不变；外部输入包含门槛、规范输入、独立姿态参考清单及实际参考载荷。

## 运动与露出结果

稳定运动阶段用后 80 对相同姿态计算循环差异。它衡量两轮随机采样的一致性，不是物理误差或整段时间方差：

| 指标 | FP16/128 | FP32/512 | 变化 |
|---|---:|---:|---:|
| 循环 RMS | 0.623992 | 0.624064 | +0.01155% |
| 循环绝对误差 P99 | 2.204772 | 2.204942 | +0.00771% |

8 帧条件分块重采样的 RMS 变化区间为 **−0.0460%～+0.0794%**，只描述这条轨迹的条件离散程度。

使用同一保守前景消失判断，两个配置都得到 **28,104 个新露出像素帧样本**和 **73 个新露出探针帧样本**。旧像素历史接受数、age>1 的像素数与探针数均为零；73 个探针样本全部标记为拒绝类别 3。新露出像素的 temporal 与当帧 Resolve 之差 P99 / max 均为零。此检查不覆盖所有亚像素或小于阈值的几何变化。

在轨迹 24、48、80、104 处，对照已有的独立同姿态 uniform current-scalar Resolve 参考，每个姿态有 1,024 个样本。矩阵、探针几何及冻结源逐项匹配，参考统计年龄保持 1；参考保留其原有探针重建，不是物理或 Unreal 真值。将当前及前三帧的新露出带重投影到同一姿态，共比较 1,459 个像素样本：

| 最近露出区域 Y 误差 | FP16/128 | FP32/512 | 变化 |
|---|---:|---:|---:|
| RMS | 1.023189 | 1.024036 | +0.08280% |
| 绝对 P99 | 2.559431 | 2.563679 | +0.16596% |
| 绝对最大值 | 2.915670 | 2.915670 | 0% |

参考分块不确定性下，RMS 变化条件区间为 +0.0612%～+0.0988%，P99 为 −0.0045%～+0.2001%。这些有限误差仍存在，本轮只说明长静止历史没有造成超出预设预算的运动回退，没有降低新露出区域的原有采样误差。

GPU 年龄进一步确认了响应机制：候选运动前有效年龄中位数为 512，第一帧实际移动后降至 **6.6816**，基线为 **6.6797**；偏移 16、32、64、128、255 帧时两个配置的年龄分位数相同。长窗口没有继续以 512 帧惯性融合这些移动接收点。

## 板边色差补查

另外用与 GI 值无关的深度 / 法线断裂构造两像素边缘带，限定朝相机的竖直板面，在四个姿态共得到 9,473 个边缘像素样本。相对参考计算 `R−G` 与 `B−G` 的误差，排除纯灰度偏移，补充亮度指标可能遗漏的串色。

候选色差 RMS **−1.1269%**、P99 **−0.9359%**、最大值 **+2.0519%**。它是额外诊断，未事后加设一个“已通过”的色差门槛；最大局部色差仍略增。`board-edge-chroma.png` 用相同绝对色标展示姿态 48 的 GI 色差，未合成最终 SceneColor。两项数值回归验证灰度变化不被误判为串色，以及等亮度色差仍能被检测。

## 判定与恢复

预先记录的运动门槛全部通过：循环 RMS / P99 增加不超过 5%，最近露出参考 RMS / P99 不超过 5%、max 不超过 10%，旧历史样本不增加。增加板边诊断后的亮度、循环、露出和门槛结果与原报告逐项相同，原报告保留为 `analysis-luminance-only.json`。

退出后实际检查相机恢复到 `(0,1.5,−3.8)`、单位旋转、FOV42；场景无脏标记，回调与 override 清空，正常 age128 / 16 px / 8 rays / 四轮 / bias0.04 已恢复，自动刷新仍为 0。未运行正在使用的 Editor 中的 Unity Test Framework。
