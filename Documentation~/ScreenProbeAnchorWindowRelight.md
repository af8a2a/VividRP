# 长窗口 scalar anchor 的统一发光响应

2026-11-15，Unity 7000.0.0a16 / D3D12，Cornell Emissive Ceiling。FP32／512 已通过本轮升光、降光、关灯响应检查，仍是诊断候选；保存的 Profile 仍为 FP16／128。还没有生产路径推广、GPU 成本或完整 Lumen 质量对齐结论。

## 条件与资格

保持原机位 `(0, 1.5, -3.8)`、单位旋转、FOV42、1920×1080，原生 Screen Probe Gather、16 px／8 rays、guarded anchor 预滤波和四轮 À-trous。Radiosity 为 8 阶／64 样本／32 批，太阳、天空和附加近场遮挡为零；顶部单面发光面片提供光照。没有调整曝光、Albedo、BRDF、π 或输出增益。

两种配置各有 constant／up／down／off 四组。每组先让实际 GPU 直射源在发光 200 下连续八次保持相同，再冷启动相机历史，等待缓存完成后预热 4,096 个渲染帧，测量 384 帧。第 64 个测量帧将发光改为 4 倍、1/4 或零；响应期没有额外停顿或重新预热。每组使用相同的显式采样帧序号。

每个响应都与其自身精度／历史配置的同帧 constant 组作物理源缩放对照。这衡量统一光源变化的响应，不是独立物理真值，也不等同于最终稳态误差。

- 2,688 对几何哈希、448 对变化前 raw 哈希一致；直接源准备屏障一致，初始与 constant 卡片源均为规范 SHA-256 `8d1b4e596e3ef067de430082d0d25763b9df83c25b57422acbdd0e33c73d6e62`。
- 四个实际 DX12 kernel 二进制与此前静止／运动实验相同；实际 anchor／previous／prepared／reconstructed 分别使用 RGBA16F 或 RGBA32F。
- 变化前五平面的候选历史年龄中位数均为 512；天花板 97.318% 的受检探针达到请求年龄的 95%，其余四平面为 100%。少数天花板槽位的年龄仍为零，没有声称全部探针历史都有效。
- 捕帧前后 2,782 份源码、3 份外部输入和实际执行脚本不变。分析前固定并复制七份本地 Python 源码，分析后复查未变。

## 响应

下表为最终 GI 的区域平均 Y 相对同帧缩放对照的误差；百分比按物理目标能量归一化。两个模式使用相同区域和掩码，所有计算采用 float64 累计。

| 区域／变化 | 前 32 帧平均绝对误差 FP16/128 → FP32/512 | 前 32 帧正过冲 FP16/128 → FP32/512 | 末 64 帧平均误差 FP16/128 → FP32/512 |
|---|---:|---:|---:|
| 天花板升光 | 0.13836% → 0.05597% | 0.31823% → 0.11456% | +0.21385% → +0.12994% |
| 天花板降光 | 0.07008% → 0.01919% | 0.24220% → 0.04995% | −0.02917% → −0.00827% |
| 地面升光 | 0.17924% → 0.05537% | 0.50309% → 0.15152% | +1.13320% → +0.50134% |
| 地面降光 | 0.15836% → 0.04124% | 0.47299% → 0.12551% | +0.63350% → +0.33802% |

候选五区域的升光首帧平均误差绝对值最大 **0.00779%**，降光为 **0.02081%**。首帧的微小差值没有被平均掉；完整曲线、各阶段误差和所有区域均保留在 `analysis.json`，汇总图为 `response-overview.png`。图中是 GI 响应误差，不是 SceneColor 对比。

预先保存的 15 个区域／变化门槛全部通过：相对基线，首帧绝对误差、前 32 帧平均绝对误差及正过冲的增加不超过 0.25 个百分点；末 64 帧平均误差绝对值增加不超过 0.5 个百分点；关灯不得留下 Y 残留。没有修改原始门槛文件。

统一升降光后仍有有限尾段偏差。基线中该偏差已在 Resolve 阶段出现，原始命中光照也不严格逐样本等于 constant 的缩放值，不能仅凭这些端点将原因归给最终滤波或历史长度。另一方面，两个精度模式在对应升光、降光组的全部 384 帧 raw 均逐位一致，因此本轮模式差异可以归于下游重建／历史精度，而非两组使用不同追踪输入。

## 关灯与有效黑色

两种模式从关灯首帧起，在全部 320 帧、五个区域、Resolve／像素时域／最终 GI 三个阶段均为未乘覆盖率的 RGB 精确零，区域最小覆盖率仍为正，最终最小值约 0.5381。额外 30 项黑色正确性检查全部通过；这项检查在候选关灯测量前记录，独立于原响应门槛，防止 alpha 为零掩盖旧 RGB。

原始探针不是完全相同的覆盖率：6,953 个有效接收点中，变化前有覆盖的为 6,297 个，关灯首帧为 6,276 个，最大覆盖率差 0.75，且两模式的计数一致。黑场会改变重要性采样方向，不能把此结果描述为全部探针覆盖不变。对应原始 RGB 为零，像素测量区域保留有效黑覆盖。

## 容量、恢复与验证范围

实际四张纹理视图的逻辑容量为 FP16 的 1,305,600 B、FP32 的 2,611,200 B，差 **1,305,600 B（约 1.245 MiB）**。这不是驱动实际显存或纹理池驻留测量。捕获保存的逐帧二进制合计 3,847,045,120 B，低于预留 5 GiB；重复 raw／几何只保留哈希和代表帧，像素区域、anchor 与统计保留完整序列。

实际默认帧检查确认回调清空、frame／À-trous／anchor override 为 −1、诊断 flags 为零、正常 age128／16 px／8 rays／四轮／bias0.04、源 8 阶／32 批；两场景干净。没有在运行中的 Editor 内执行 Unity Test Framework。

两项 Python 数值回归通过，覆盖统一源缩放的零误差不变式、首帧 14% 缺口和关灯残留的可观测性。这里没有重做静止降噪主实验；其结果及固定轨迹验证分别见 [精度／长窗口实验](ScreenProbeAnchorPrecisionExperiment.md) 与 [运动验证](ScreenProbeAnchorWindowMotion.md)。短 384 帧 constant 窗口的五区域均值变化绝对值最大约 0.9504%，不以它替代此前更长窗口的均值与方差验收。

本轮只覆盖纯自发光的统一标量变化，不覆盖任意局部光照、颜色改变、几何运动、Sponza 或 Unreal 物理能量对齐。下一步仍是可靠 GPU 成本和生产配置路径验证。
