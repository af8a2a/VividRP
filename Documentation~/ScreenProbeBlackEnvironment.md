# 黑色环境分类与长窗口噪声实验

本轮证明了无天空 Cornell 中一类已完成的 miss 可以作为有效黑光照；修正后覆盖率和方向历史年龄提高。但默认引导路径没有通过边缘噪声门槛，长窗口也出现更强的低频起伏。**候选未进入默认，生产追踪 shader 已精确恢复。** 新增内容是可复用的内存候选、分类检查和长窗口诊断，不是已接受的画质改进。

起点 `8e98a672`；生产渲染基线仍为 `7b9d8836`。证据位于 `E:/VividRP_GI_Evidence/ScreenProbeBlackEnvironment-20261116-084500`。Unity7000.0.0a16 / CoreRP17.7 / D3D12，纯自发光 Cornell 原机位，原生 Gather、16 px / 每探针8 rays，FP32 anchor / age512、像素历史上限32、4轮 wavelet。Radiosity 固定8阶、64样本、32批，输入 hash 为 `40252e7ae82c1da6ae025dbf012a3ce232aa54ea10bfbf1ca9a7998df93270a8`。

## 分类和能量不变量

只对 `SkyType.None` 的完整 SDF miss，在没有屏幕拒绝、具有有效 Mesh SDF 根节点，且光线已经离开根 AABB 时，记为有效黑色环境。仍在场景范围内的有限距离 miss、追踪未完成、屏幕阻挡、卡片缺失和背面拒绝均保留原语义。不向这些方向补入天空能量。

`micro` 在同帧、同方向上比较两种分类，64测量帧共 **8,355,840条射线记录**：

- 972,073条被改为有效黑光照；其余状态位不变，全部几何与逐射线 RGB 逐字一致。
- 有效探针平均 coverage 从0.67258升到0.99918，没有 coverage 降低。
- `raw.rgb × raw.a` 总量只变 +0.00376%；逐分量误差通过 `0.0002 + 0.002 × max(abs(before), abs(after))` 的 FP16界限。
- 单个分量最大绝对差0.05469、最大相对差约0.09085%；不能把“保留能量”描述成消费结果逐字一致。

独立 GPU 检查覆盖14种边界条件与3种开关/节点状态，共42项通过。它使用候选原函数、生产 MeshSdfTrace include 和实际 CPU Node 类型，核对 stride48、Min偏移0、Max偏移16；不是仅做 CPU 几何推算。

## 全链路质量门槛

每组按帧核对实际深度、GBuffer0/1、探针与像素接收几何、VP和逆VP。场景输入与固定 Radiosity 一致后才比较质量。均匀方向要求逐样本消费能量在 FP16界限内；默认引导会通过历史反馈改变方向，另按事前协议要求全局消费 RGB 各通道均值变化不超过1%。

事前门槛是受影响 `floor/back` 至少一个方差下降5%，所有最终 ROI 方差增加不超过2%，平均能量变化不超过1%。以下方差来自最终 GI 消费信号、接收材质反射率相乘之前；没有声称与 Unreal 或物理真值一致。

| 128帧窗口，1024帧预热 | 天花板方差 | floor 方差 | back 方差 | 混合边缘方差 | 结论 |
| --- | ---: | ---: | ---: | ---: | --- |
| 均匀方向 | −58.35% | −17.21% | −11.74% | +0.15% | 本窗口通过 |
| 默认引导 | −48.46% | −17.66% | −15.77% | **+4.29%** | 边缘门槛失败 |

两组平均能量变化均在1%内。这里 `floor` 探针条带混合地面与短盒子正面，`back` 条带是高盒子正面，`edge` 混合多片几何；条带的阶段指标与全分辨率 ROI 是不同采样范围，不可互相替代。报告保留失败区域和块统计区间，没有删除边缘或放宽门槛。

## 长窗口区分快闪和慢变

默认引导另做4096帧预热、1024帧测量。逐像素在线累加 FP64 的 ΣY、ΣY²、相邻帧差平方、64帧分块和；128帧验证捕获将所有累加项与完整原始序列重新计算比对通过。长窗口保留前64帧、端点与所有聚合量，减少原始帧占用。

| 最终 ROI | 平均能量变化 | 总时域方差变化 | 相邻帧差 RMS 变化 | 64帧块均值 RMS 变化 |
| --- | ---: | ---: | ---: | ---: |
| 天花板 | −0.45% | −48.67% | −62.54% | −27.85% |
| floor | −0.29% | **+4.42%** | −48.02% | +2.54% |
| back | +0.79% | **+7.15%** | −89.84% | +7.31% |
| 混合边缘 | −0.01% | **+21.24%** | −10.98% | **+21.92%** |

相邻帧变化更小，同时较慢的明暗波动更强。平均能量门槛通过，方差门槛失败。长窗口没有撤销原128帧失败，也不是独立随机序列或动态响应验收；分块量仅作描述，没有伪造独立样本置信区间。因此停止推广，不继续对该候选做移动与 GPU 性能验收。

## 可复用工具与恢复

`BuildScreenProbeBlackEnvironmentMicro.py` 生成同帧分类/能量实验；`BuildScreenProbeBlackEnvironmentQuality.py` 生成128或1024帧原生链路实验。后续使用 `BuildSdfBlackEnvironmentCandidate.py` 和 `ScreenProbeExperimentalTracing.cs.txt` 创建内存 shader，编译9个 DX12内核并核对索引，结束时恢复原 shader、销毁候选、清理实验相机历史。生产资产不需要修改。`ValidateSdfBlackEnvironment.cs` 可在连接的 Editor 中执行42项检查，不调用 Unity Test Framework。

迁移到内存后的 `transient-uniform-corrected` 与早先原型核对了5,893条记录：全部 raw、方向历史、几何和实际输入 hash 一致，状态/矩阵一致；**scalar anchor 和后续输出并非逐字一致**。这次只通过追踪层复现，不能描述为全链路重复性或独立质量通过。差异按 tag 保存在 `transient-reproduction.json`，为下一轮 scalar anchor 定位保留线索。

生产文件与实验前备份逐字一致，9个原生 DX12内核编译通过。恢复后重新预热1025帧，并检查正常帧的16/8、age512、4轮 wavelet、诊断0、空回调、干净场景，以及原时域/小波程序 hash。原持久化 Hybrid 追踪已恢复；Frame Debugger关闭，PIX空闲。

Python工具测试115项通过。Editor正在运行，未运行 Unity Test Framework；未作 GPU 提速或最终无噪点声明。本轮清理先前已撤回实验的部分内部帧，共释放1,212,876,800字节，保留源文件、hash、报告、聚合量和完整端点；各目录的 retention 日志记录了原始序列不再完整可重算的范围。

下一步在相同16/8和固定源缓存下分离“引导反馈”与“scalar anchor 收敛”：先要求长窗口能量与边缘方差通过，再进行移动和开销验收。分类修正本身不能替代这一质量门槛。
