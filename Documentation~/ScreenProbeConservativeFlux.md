# Screen Probe 小波守恒归一化实验

2026-11-16，Cornell Box / Unity 7000.0.0a16 / D3D12。实现并实测固定归一化、成对对称的能量通量小波。**全屏离散能量检查通过，但独立物理参考的地面均值图 MSE 回退，因此拒绝启用候选，生产默认保持原值。** 这次没有解决上一轮第二序列 back 的边界验收问题。

证据：`E:/VividRP_GI_Evidence/ScreenProbeFluxNormalization-20261116-162900`。承接 [消费能量域 moments](ScreenProbeEnergyMoments.md)，保持 16 px / 每探针 8 射线、anchor 512、pixel 32、四轮小波、bias 0.04。冻结 8 阶 / 64 样本 / 32 批 Radiosity，固定机位，序列 1733，预热 1024 帧后测量 128 帧。未降低原门限。

## 算法与实际消费验证

原双边滤波按每个中心像素自己的权重和归一化，即使部分原始权重对称，归一化后也未必对称。新实验滤波最终消费量 `E = RGB × abs(coverage)`：

```text
a_ij = binomial_ij × bilateral_ij / 256
E'_i = E_i + sum_j a_ij × (E_j - E_i)
```

5×5 二项核总和 256；双边因子均不大于 1，除去中心后的系数和不大于 220/256。交换系数同时使用两端的法线、材质、世界空间平面距离、能量亮度、方差和对称 coverage 置信度。预计算两端的方差及粗尺度几何边界许可；任一端拒绝时，两端都不交换。精确算术下成对通量相消，常量保持不变，输出为非负凸组合。半精度输出显式 round-to-nearest-even，保留覆盖率；HDR 上限仍为 65000。

`ScreenProbeConservativeFlux.py` 生成三个 owned kernel：准备引导、滤波、最终滤波。使用一个 1920×1080 RGBA32F 引导纹理，约 31.64 MiB，实验结束释放。没有修改生产 GPU 接口、RenderGraph 资源、Runtime 或生产 shader。

原生 Editor 小波回调在每轮原 dispatch 后，用同一输入覆盖该轮输出和中间方差，下一轮及最终画面实际消费新结果。独立候选重放同一程序，独立控制保留原时域及原小波。132 对全图 Resolve、3300 对原生/独立候选的颜色、历史、moments、几何与最终输出逐位一致；冷启动能量域统计校验也通过。**原小波 dispatch 仍执行，因此该注入方式只能验证质量和消费链，不能测候选最终 GPU 成本。**

在首、末测量帧的四个尺度各读回滤波前后全屏 FP16 RGBA，共 16 次读回。检查每对 coverage 哈希相同、相邻尺度形成同一消费链、无非有限值、负值或 HDR 饱和。允许的数值误差事先固定为输出各通道半 ULP 累加，再加输入总量的 `2e-6` FP32 运算容差。所有八对通过；最大 RGB 总量变化 **0.0001214%**，误差/界最大 **0.003468**。这是屏幕像素离散 `RGB×coverage` 总量检查，不是按表面积积分的辐射守恒，也不保证局部 ROI 或物理真值正确。

## 质量结果与停止条件

`flux-a-v2` 的源码前后核验通过，2788 个文件、3 个外部输入和实际执行脚本未变。三个新 kernel 通过实际 DX12 编译，捕获 complete、errors 为空。下表完整 ROI 时间方差与固定 4 px 网格物理参考为不同统计支持，分别报告。

| ROI | 完整 ROI 时间方差下降 | 逐帧差 RMS 变化 | 抽样 Y 时间均值图 MSE 变化 |
| --- | ---: | ---: | ---: |
| ceiling | 32.26% | −53.30% | −45.46% |
| floor | 12.99% | −32.44% | **+4.91%** |
| back | 21.60% | −33.66% | −3.04% |
| edge | 0.42% | +1.72% | −0.25% |

原完整 ROI 的 1% RGB/Y 均值、5% 天花板降噪、其他 ROI 方差最多增加 2%、逐帧差最多增加 2% 均通过。

物理参考复用已固定的精确几何 Lambert `E/π` 独立路径：2336 点，天花板及 back 每点 131072 路径，其他点 16384，9 次反射。实际 GPU 位置和解码法线、几何投影、fixture 及父参考完整哈希均通过，未重算或拟合参考。

地面 Y 均值图 MSE 增加 **4.9115%**，含三倍独立参考标准误的上界 **5.1063%**，最差 RGB 点估计增加 **4.9859%**，超过原 1% 门限。地面相对参考的平均 Y 偏差从 +3.1040% 变为 +3.2401%。此外，所有 RGB/Y 通道的保守新增绝对均值误差界在 ceiling 最大 0.2801%、edge 最大 0.2187%，未通过原 0.2% 门限。该界是三角不等式保守界；ceiling 的实际平均 Y 误差从 −0.5362% 改善到 −0.2651%，不应把界超限描述成已证明平均物理误差恶化。

故停止该候选，不运行第二序列、移动或动态光照验收；这些项目与原生 GPU 成本均未通过本轮验证。全屏守恒不能作为局部能量正确的替代指标。单一复合候选同时改变统计域、空间权重及颜色存储舍入，当前证据不能把地面回退唯一归因于其中一项，也不能与旧跨批次结果作严格因果相减。

下一步应在同一实际输入及同一能量域 moments 下增加反事实重放，分离原逐行归一化、成对通量、FP16 颜色舍入的影响。保留独立参考与原门限；先定位局部均值偏差，再决定新的空间重建候选。

## 工作流、恢复和空间控制

首轮 `flux-a` 漏做源码前置快照。其 complete、DX12 编译和离散总量检查不能补成合格画质证据；记录明确标为 `sourceQualified=false`，随后以 `flux-a-v2` 重跑。未补写虚假的“测前快照”。捕获生成工具现已在写出协议、参数、全部实际 shader 与脚本后自动创建 `source-before-capture.json`；生成失败时调用方不得启动实验。准备检查实际固定 2787 个文件、12 个外部输入及执行脚本。实验后仍须运行：

```powershell
python Tools~/Diagnostics/VerifyGiSourceSnapshot.py <case>/source-before-capture.json <case>
```

178 项 Python 检查通过，包含成对交换守恒、常量/非负性、两端边界隔离、缺失读回与 coverage 变更拒绝，以及自动前置快照。活动 Editor 未运行 Unity Test Framework。工具在合格重跑及其源核验完成后增加自动快照；实际捕获 shader、脚本、协议及本轮分析结果保持原文件。

结束前运行 1024 帧原路径预热，原时域及两个小波 DXIL 与原 Hybrid trace 核验恢复。回调为空，override −1、flags 0，16/8、anchor 512、pixel 32、四轮及源 8 阶/32 批保持原值；两场景干净，PlayMode 暂停、Frame Debugger 关闭、PIX idle。没有本轮 PIX 捕帧或 Editor 重启，没有创建目录别名。

合格重跑完整读回保留；不合格试跑逐项无损 ZIP 解压校验后清理原始副本，保留协议、脚本、聚合、状态说明和全部可恢复数据。具体释放量及当前容量见证据根目录的 `post-experiment-storage.json`。不因失败删除验收依据。
