## 实现及验证约束

`ScreenProbeEnergyMoments.py`生成内存时域shader，替换当前pass的`m_GatherTemporalCompute`，并让独立候选重放同一个程序。八个kernel ID必须与原程序一致；只编译并使用本实验所需的moments kernel。清理时先恢复原字段，再销毁owned shader；字段若被外部更改则报告错误，不覆盖其他操作。

变更只涉及统计及其引导量：

- 当前观测记录`log2(1+Y(RGB×coverage))`。原颜色历史本来已经保存覆盖能量；重投影统计也改用这个量，避免再次除coverage。
- moments的重投影混合用几何双线性权重；其有效支持度按有效历史足迹归一化，避免对已经包含coverage的能量再乘一次coverage权重。
- 灯光缩放的log均值修正与Jacobian、历史裁剪引起的均值修正都使用能量域。像素颜色历史的读写、运动/深度/法线拒绝、age及coverage编码保持原逻辑。
- 小波中心/邻居的亮度距离与moments使用同一能量域，颜色沿用covered-energy平均；本轮不启用上轮的对称coverage实验，也没有改逐行归一化。

原控制仍用原时域与原小波，拥有独立历史。静态每组132对全图Resolve、3300对原生/独立候选的temporal、history、moments、geometry、final逐位一致；移动组为132与1320对。原协议仍保留旧验证规则。新模式只允许冷启动moments均值不同，并另检查：候选均值对应能量log、控制对应条件RGB log，方差/age/coverage一致；GPU浮点到FP16的预测允许最多一ULP。没有移除原生与候选的全图A/A。

`--wavelet-witness`不能与能量moments混用，因为旧条件RGB小波不应拿能量域moments作为对照。原单域小波实验接口保持可用。

## 静态结果

四个ROI的完整像素时间方差，以及固定4px网格的2336点物理参考是不同统计支持，分别报告。下面MSE是128帧时间均值图的Y误差，不是无限时间误差或整幅图指标。

| ROI | 完整ROI时间方差下降：1733 / 9481 | 抽样Y均值图MSE变化：1733 / 9481 |
| --- | ---: | ---: |
| ceiling | 42.36% / 47.83% | −35.75% / −47.25% |
| floor | 20.37% / −1.51% | −2.95% / −4.56% |
| back | 27.26% / 27.77% | −3.77% / +0.956% |
| edge | 5.07% / 2.30% | −2.04% / −0.35% |

第二组floor的方差确实增加1.51%，在原2%容限内；各ROI逐帧差RMS都下降。天花板下降51.50% / 53.10%。所有RGB/Y新增绝对均值误差的保守界最大0.1718%，通过0.2%门限；原完整ROI各通道均值1%门限也通过。

`ExtendCornellPixelOracle.py`只为back的384点增加每点131072条独立路径，保留既有天花板288点的131072路径与其他1664点的16384路径。种子不与父参考重叠，父metadata、父完整记录、新记录及积分器hash均核验。新驱动保留旧已固定驱动文件；分析器要求未替换的点与父记录完全一致。此次back细化耗时292.86秒。

高样本参考下，第二组back的Y MSE增量为0.9556%，三倍参考标准误上界1.0807%；最差RGB通道点估计0.9882%，上界1.1172%。点估计通过原1%，但上界仍未通过，故`addedMeanMapMseThreeSigmaGatePassed=false`保持真实状态。没有把增加样本解释成已证明没有回退。第一组全部参考门限通过。参考仍是精确几何Lambert `E/π`，不是OpenPBR或Unreal等价性证明。

## 固定轨迹与新露出区域

沿用128帧轨迹：横移0.28m、前后0.06m、yaw7度。3894个明确新露出像素样本分布在73帧；两条路径旧age比例和历史接受率均为0，temporal−自身当前Resolve的P99/max均为0。四分层只在首个测量帧满足资格，能量moments与小波在全部128帧持续启用；报告分别标记这两件事。

最终小波输出与noisy当前Resolve的差异更大，不能直接称为拖影。因此`ScreenProbeEnergyMotionReference.py`对既有4px网格与新露出掩码的交集建立独立参考，不按误差大小挑点。共199个像素帧样本，实际GPU位置投影到对应精确表面的最大法向校正1.431微米，使用实际解码法线；每点16384路径、9次反射。

相对物理参考，原路径/候选的绝对误差P99为2.94857/3.01899，max为3.70406/3.71182，变化+2.388%/+0.210%，通过事先写入协议的5%点估计门限。候选平均绝对误差1.13604（控制1.12811），MSE1.92399（控制1.88649），没有宣称所有移动指标改善。参考Y标准误中位数0.02638；只检查199个新露出样本，不代表全部3894样本、持续运动平面或整幅图，也没有完整概率置信界。
