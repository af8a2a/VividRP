# Cornell Box：空间重建 SH 能量 anchor 实验

2026-11-11；Unity 7000.0.0a16，D3D12，RTX 5070 Ti。

## 结果与使用范围

用连接可靠的同平面邻居重建校准目标后，Cornell Box 静止平面的噪声明显下降，平均能量通过预先设定的 2% 门槛。

默认重要性引导开启时，天花板探针时间残差方差从 **66.815 降至 25.677**，下降约 **61.6%**；后墙下降约 88.2%，地面下降约 74.6%。相对独立高采样参考的区域平均能量偏差分别为 **−0.083%、−0.878%、−0.318%**。逐探针平均误差 RMSE 也下降，没有仅靠区域内正负误差抵消通过检查。

现有像素时域和两轮 À-trous 之后，选定天花板像素 ROI 的时间方差从 **6.074 降至 3.441**，下降 **43.3%**，平均亮度变化 **+0.136%**。低频杂斑仍然存在，本次并未消除全部间接光噪声。

新增 Volume 选项 `screenProbeSpatialAnchor`，仅在原生 Screen Probe Gather 下生效，**默认关闭**。本轮验证固定 Cornell 机位和静态平面；移动、薄几何边缘、Sponza 与 GPU 耗时仍未验证，暂不修改已有 Profile 或默认渲染行为。

## 实现

在 `SdfScreenProbeFiltering.compute` 增加 `ScreenProbePrepareAnchorCS`，先将实际 raw anchor 做原有时域累积，写入独立临时纹理。随后 Convert 只改变 SH 的校准目标，`m_Probes` 仍保存中心 temporal anchor，避免把空间平滑结果再次写回标量历史而产生反复扩散。

重建使用固定 5×5 基础探针网格，处理 coverage 加权的能量：

```text
E_i = temporalAnchor_i.rgb * coverage_i
E'_i = E_i + sum_j(w_ij * (E_j - E_i))
calibrationTarget_i.rgb = E'_i / coverage_i
```

- 权重由几何与固定空间核决定，不使用噪声亮度阈值裁掉明亮贡献。
- 同时检查两端法线、对称平面距离、世界距离；在屏幕连线上读取三处深度和法线，拒绝可见的前景阻隔。
- 法线点积阈值 0.995；平面容差包含 8-bit oct 法线量化误差；世界半径为 `clamp(0.08*min(depth_i,depth_j),0.08,0.35)`。
- 核归一化固定为完整 5×5 Gaussian 权重之和 `7.84736875`，而不是按实际获准邻居重新归一化。被拒绝的份额留在中心，双向连接使用相同权重，保持对称能量交换。
- coverage 小于 0.25 的中心保持原目标；无效邻居不参与。Adaptive 探针保留自身 temporal anchor，第一版不让它们参与基础网格的能量交换。
- 重建不提高 coverage，不凭邻居补出原先不存在的有效命中；校准继续保持 SH 在自身法线方向与选定目标一致。
- 开关变化纳入历史有效性检查；新增 scratch 声明为 RenderGraph transient read/write。1080p、双层探针 atlas 的有效纹理数据约 127.5 KiB，实际显存分配和对齐未测量。

## 采样与参考

沿用前次实验的 Cornell Comparison Camera、3600 lx、EV8、1920×1080、16 px 网格、每探针 8 条射线、Adaptive 5×5、两轮 À-trous、像素历史 16、Surface Cache B 的 37 张卡片及 8 阶反弹。

四个常规组为“重要性引导关闭 / 开启”分别搭配旧 anchor / 空间 anchor。各组预热 128 帧，连续记录 256 帧。主要因果对照使用新路径同一帧的中心 temporal anchor 与实际 SH 输出，二者具有完全相同的射线输入；另外独立运行旧路径，检查最终像素结果。

高采样参考关闭重要性引导，使用两个独立帧号序列；各预热 128 帧、记录 1024 帧。每帧的 8 条余弦分层射线贡献在**时域 / 空间滤波之前**累积，未解析射线计零，合计 **16,384 次射线贡献 / 探针**。没有把旧 temporal、未校准 SH 或去噪后的画面当作参考。

这是当前 Hybrid 追踪和已发布 Surface Cache 光照的 Monte Carlo 参考，仍包含现有 SDF、卡片覆盖及固定反弹解的误差，**不是独立路径追踪的物理真值**。

最终 3072 个测量帧的 VP 矩阵完全相同，太阳均为 3600 lx，反弹阶数均为 8。法线打包值逐位相同；仅两个测量帧出现位置末位差异，最大 `4.77e-7 m`，远小于采用的 `1e-5 m` 接收点一致性容差。

| 区域 | 探针数 | 高采样平均 Y | 两独立序列均值差 | 均值 95% 半宽 |
|---|---:|---:|---:|---:|
| 天花板 | 168 | 56.07079 | −0.0862% | 0.08561 |
| 后墙 | 230 | 30.44765 | −0.0004% | 0.03880 |
| 地面 | 65 | 51.49114 | +0.0516% | 0.13629 |

探针区域、readback 方向与统计定义沿用 [前次 anchor 实验](ProbeAnchorCalibrationExperiment.md)。Y 为线性 GI 亮度，统计 coverage 加权的实际贡献，去掉每个探针自己的时间均值后计算方差。低频 RMS 对时间残差做 σ=1 个探针的 Gaussian 低通。能量偏差使用同一批接收点，不混用不同空间区域的平均值。

新旧独立运行的区域能量变化为 `+0.119%、+0.100%、−0.517%`。

用 32 帧 block bootstrap 同时计入常规采样与参考的不确定性，新路径平均能量偏差的 95% 区间为：天花板 `[−0.4325%,+0.3103%]`、后墙 `[−1.1421%,−0.6186%]`、地面 `[−0.9311%,+0.3243%]`，均在 ±2% 内。

区域平均 RGB 相对参考的最大通道偏差约 1.01%；没有明显去饱和或只在亮度总和中隐藏较大的颜色漂移。

同帧新目标相对中心 temporal anchor 的方差比分别为 `0.3854、0.1169、0.2526`；天花板方差比的配对 95% 区间为 `[0.3775,0.3938]`。独立旧路径数值与同帧旧目标存在少量差异，因此上表不作为逐位确定性的声明。
