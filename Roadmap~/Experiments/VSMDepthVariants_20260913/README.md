# 深度布局、有效层范围与重复加载对照

2026-09-13。基线为 `70f4eb9b` 的有序深度查找。完成三类候选的性能与正确性对照后，**本轮均不纳入默认渲染路径**。五个实验涉及的源码文件已按原始字节恢复；16 层容量、已有求交规则及上轮有序查找优化均保留。

## 结论与实现范围

| 候选 | 本轮具体实现 | 测量结论 |
|---|---|---|
| 深度层布局 | R32_UInt Texture2DArray 容量不变，将低两位层号与 2×2 texel 的坐标低位交换，使四层在物理 texel 中交错；写入、清页、占用归约和读取使用同一映射 | 4096 稳态 Trace 约从 7.03 ms 增至 23.90–24.37 ms；清页和持续重绘也退化，拒绝该布局 |
| 有效层范围 | 在现有页 flags 中编码静态／动态池各自的最大有效层数，使用现有占用归约生成上界；静态页可缓存，动态范围每帧更新 | 页粒度偏粗，独立编译未超过原基线，持续重绘增加构建成本，拒绝该实现 |
| 重复加载 | 每个 Resolve 线程缓存最近一次首层查询的物理 texel 与静态／动态深度对；相同坐标才复用 | 切换试验没有稳定收益，独立编译仍更慢，拒绝该缓存 |

这些结果对应上述三个具体实现；其他分组布局、范围粒度或复用方式仍需单独测量。

## 性能证据

RTX 5070 Ti，Unity 6000.7.0a6，DX12，1920×1080；Sponza + SponzaLightingDay，AA=None，定向光角直径 7.1°。固定 1024 页、16 层、四射线，自适应关闭，8 samples/segment，最大光程 10。使用未插入 Nsight 的 GPU ProfilerRecorder；本轮没有采集新的 Nsight 硬件计数。

共完成 60 个窗口，每窗预热 64 帧、记录 128 次观察，共 7,680 次观察。表中每个范围表示重复窗口的中位数范围，不是单帧最小／最大值。所列目标 marker 的每帧样本数均为 1。各窗口保存有效参数、页计数、元数据和前后状态。

首先在同一着色器内测试 2 种布局 × 4 种范围／复用组合 × 2 种分辨率，再反向重复，共 32 个窗口。对应的稳态驻留／请求页为 2048 的 266／266、4096 的 641／641，没有新增页或溢出。

## 有效范围和访问方式的解释

2048 的 266 个驻留页中，138 页至少有一个 texel 达到 16 层；4096 的 641 页中，304 页达到 16 层。其余页的最大有效层数为 4–15 层。页级上界能减少部分查找区间，但无法区分同页内浅层和深层 texel。稳态静态范围可缓存；持续重绘时必须重新建立，构建成本抵消了有限的查询收益。

交错地址映射是 2×2 texel／四层块内的双射，保持全部 16 个逻辑深度值。它同时把原来的二维相邻 texel 分散到不同 array slice：改善层间相邻性会牺牲部分空间相邻性。这个源码层面的权衡与清页、光栅化和 Resolve 同时退化相符，但本轮没有逐 load、缓存或寄存器硬件指标，不能据此确诊 bank conflict、spill 或某一级缓存失效。

最近首层缓存增加了地址比较和跨查询保存的线程状态。DDA 通常继续走向新 cell，不同射线也可能从不同 PCF 偏移开始；本轮没有统计实际缓存命中率，不能把退化简单归结为“命中率低”。实测没有显示足以抵消成本的收益。

## 正确性与验证范围

- **GPU 区间 oracle：**8 个布局／范围／复用组合，共 1,048,576 个案例；289 种独立静态／动态层数配对、全部 16 层、不同深度尺度及边界条件，零差异。
- **生产 Resolve 同帧对照：**范围、复用及二者组合，在 2048／4096 下覆盖静止、相机平移、太阳旋转、临时遮挡物运动。共 24 组、192 帧、398,131,200 个像素，原始 Resolve 输出逐位一致。比较使用相同当前页面、历史与随机相位；未分别运行两套独立滤波历史。
- **真实光栅化深度：**保存原布局深度，分别与原布局再次重绘、交错布局重绘比较，包含静止和持续更新的临时 cube。静态／动态池及物理页所有者均零差异；合计 1,906,311,168 个深度值比较，包含控制组与重复数据。
- **动态池覆盖限制：**原生 2048 检查中动态池约有 12.3 万个非零深度值；原生 4096 检查中动态池为空。因此不能声称原生 4096 的非空动态池已得到独立覆盖；任意池层数组合由 GPU 合成 oracle 覆盖。
- **编译：**实验版本 52 个 compute 入口通过 DXC；两个实际 caster 写入路径的最小 pixel shader 包装也编译成功。原生场景验证同时执行了真实写入路径。C# 生产源码没有修改，Unity Test Framework 未运行。
- **约束：**层数、求交比较、光程、DDA、gap fill、厚度和 bias 沿用基线。范围只缩小有证明的页内层上界；缓存只复用同一物理 texel 的首层深度对。

原生验证记录写出且临时资源释放后，首个诊断 Editor 发生 DX12 `0x887a0006` device-hung；日志明确没有报告 Local／Non-Local 显存耗尽，具体原因未定位。后续性能测量在重启后的实例中单独完成。第二个实例在首层复用窗口完成后正常退出，末尾原基线控制未能启动。两项情况均保留在 [final-verification.json](E:/VividRP_Reborn/Packages/VividRP/Roadmap~/Experiments/VSMDepthVariants_20260913/final-verification.json)，未把未完成的窗口计入结果。
