# 通用 VSM 细层覆盖与页预算质量闭环（2026-09-11）

已落地通用视图覆盖、可配置页预算和独立 coverage 过渡，并完成真实 PCF / 现有 SMRT 的静止、平移、转头验收。当前 Sponza 轨迹建议使用 **4096 分辨率、1024 页、View Coverage 开启、Screen Density 开启、Target 1、First Level 0、Coverage Transition 0.05、LOD Transition 0.2**。这是测得的动态质量档；原场景已恢复，默认仍为 256 页、View Coverage 关闭。

**实现及兼容性**

- 由非抖动相机视锥在光空间的范围决定中间 clipmap 的偏移，支持透视／正交相机、FOV、宽高比、朝向和分辨率变化；没有固定 L3 或场景坐标。最近和最远层保持原布局，页对齐、父子一页保护边界、投影尺度与深度基准保持不变。
- 移动时使用 0.25 页迟滞，并将历史独立于每帧 Context Reset 保存。检测到视图停稳后恢复规范页窗，消除由运动路径留下的持续覆盖损失。
- 页预算支持 128–1024，默认 256。物理池、深度切片、所有者表和栅格页列表保持容量一致；仅有效描述变化时重建。
- Coverage Transition 和 LOD Transition 分离。旧 Volume 没有覆盖新字段时继续沿用旧的 transition，保留现有序列化配置语义。
- 本次没有改动 SMRT 光线步进、采样序列或降噪算法。原有未提交的 joint sampling 修改已保留。

**动态闭环发现并修正了两个问题**

1. 768 页足够容纳当前请求，但未必能保留运动历史。PCF 平移请求峰值 645，而 1024 页对照中历史驻留峰值达到 987。768 页出现的少量最多粗四级的点，在 1024 页对照中不再出现。SMRT 当前请求峰值 674，平移时驻留触及 1024；这仍是有限预算，不能外推为所有轨迹都不淘汰。
2. 迟滞页窗曾让相同停稳机位保留不同原点，导致约 2311 个诊断点持续粗一级。最终实现只在视图变化时保留迟滞；停稳恢复后，该持续差异消失。

![预算、历史驻留与停稳恢复](E:/VividRP_Reborn/Packages/VividRP/Roadmap~/Experiments/VSMGeneralCoverage_20260911/budget-history.png)

两条路径的最终验收均为 **零预算溢出、零最终不可用、零最粗 L9 回退**；360 个详细诊断帧的页表、元数据、物理槽所有权全部一致，独立 GPU 回放误差 ≤0.0004883（RHalf 输出量化范围）。静态新分配为零。SMRT 比较的 256 对帧同时匹配相机姿态、TSR 抖动和蓝噪声 256 帧相位。

仍有运动中的短暂退粗，因此本轮完成的是可复现的覆盖／预算质量闭环，并未声称运动阴影完全无跳变。诊断中的尝试缺页计数与“最终不可用”不同，报告没有把粗层回退成功当成细层质量达标。

**显存和性能代价**

纹理字节按实际描述计算，包含静态池、动态池、逐页 Depth32 切片与 2048² Unity 兼容深度，不含驱动分配对齐、压缩、CSM 图集和其他管线资源。

| 页预算 | VSM 相关纹理 | 相对 256 页增加 |
| --- | ---: | ---: |
| 256 | 64 MiB | — |
| 384 | 90 MiB | 26 MiB |
| 512 | 114.125 MiB | 50.125 MiB |
| 768 | 162 MiB | 98 MiB |
| 1024 | 208 MiB | 144 MiB |

实际 Sponza 计时会话的相关 GraphicsBuffer 另约 3.02 MiB。资源单独验证使用小场景输入容量，JSON 中较小的 bufferBytes 不代表实际 Sponza 总缓冲区内存。

独立计时使用 RTX 5070 Ti、D3D12、Unity 6000.7.0a6，1920×1080 NativeAA TSR。PCF 静态场景，5 秒预热 + 5 秒采样，五种配置按正反顺序各一次。以下是两个窗口的阶段中位数范围；采样期间没有质量读回或压缩。

| --- | ---: | ---: | ---: |
| 原布局 256 | 0.470–0.489 ms | 0.033–0.035 ms | 2.015–2.088 ms |
| 原布局 768 | 0.410–0.412 ms | 0.092–0.101 ms | 1.668–1.931 ms |
| 通用覆盖 512 | 0.921–0.924 ms | 0.062–0.063 ms | 1.974–2.024 ms |

512 页虽然省显存，持续页池竞争使分配阶段更贵。1024 页增加清页与显存成本。整帧 CPU/GPU timing 没有有效样本；阶段计时来自编辑器全部相机，不能认证单个相机的整帧预算，也不能直接相加阶段分位数。这里没有给出 SMRT 性能提升结论。
