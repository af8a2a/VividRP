# A Beautiful Game — VividRP assets

This package copy supports the built-in **A Beautiful Game — VividRP Path
Tracing** SceneTemplate.

Contents:

- `glTF`: the CC BY 4.0 Khronos sample source used by UnityGLTF.
- `Materials`: VividRP StandardLit materials, including solid dielectric
  transmission for the pawn tops.
- `Textures`: metallic and roughness channel assets derived from the source
  glTF ORM textures.

The scene template itself is stored under
`Editor/SceneTemplates/ABeautifulGame`. It uses the VividRP built-in HDRI,
automatic exposure, emissive mesh lighting, and no Unity punctual or
directional lights.

Source and detailed model information:
[KhronosGroup/glTF-Sample-Assets — ABeautifulGame](https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/ABeautifulGame).
